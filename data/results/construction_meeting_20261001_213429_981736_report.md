### Выявленный вопрос

Можно ли объединять вентиляционные каналы разных квартир в один общий канал в многоквартирном доме?

**Причина проверки:** Вопрос о возможности объединения вентиляционных каналов требует проверки соответствующих нормативных положений.

### Ответ

Согласно СП 60.13330.2020, объединять воздуховоды **внутри одной квартиры** допускается лишь при выполнении определённых условий (использование индивидуальных поквартирных приточно‑вытяжных установок с рекуперацией, подключение спутников к сборному воздуховоду, расположённому в межквартирном коридоре) [ SOURCE_5 ].  

Для **общего сборного вертикального воздуховода** рекомендуется устройство самостоятельных спутников для санузлов и кухонь, то есть каждый жилой блок (квартира) должен иметь отдельный ветвящий элемент. Прямого допуска объединения вентиляционных каналов разных квартир в один общий канал в нормативном документе нет, следовательно, такое объединение не предусмотрено.  

**Ответ:** объединять вентиляционные каналы разных квартир в один общий канал в многоквартирном доме нельзя; допускается только отдельное подключение каждой квартиры к общему сборному воздуховоду через самостоятельные спутники [ SOURCE_5 ].

**Статус:** Нормативное требование найдено
