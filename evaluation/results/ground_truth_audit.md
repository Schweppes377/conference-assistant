# Обновление методики: оценка по тексту и говорящим

Текущий статус: **ожидается ручное подтверждение аудио**. Сценарные тексты не
объявляются фактически проверенной речью. Новый dataset содержит 27 реплик с
двумя ролями и восемь вопросов без start/end. HTML больше не требует временной
разметки. Нормативные expected_sources и 19 chunk IDs сохранены точно.

По запросу пользователя изменены только evaluation/schema и интерфейс проверки.
Production, pyannote, ASR, RAG, индекс, prompts и старые baseline-результаты
сохранены. Новый matching=text с cosine threshold 0.2 относится к текстовому
сходству и заменяет time matching только для этого dataset. Метод и фиксированные
признаки тем подготовлены по сценарию до оценки нового baseline; метрики не
использовались для подбора правил. DER не рассчитывается для этого эксперимента.

Speaker Attribution Accuracy использует точное выравнивание слов по Levenshtein,
охват не менее 0.5 и большинство speaker votes. Соответствие анонимных меток
говорящим одно для всей записи; выводятся охват, несопоставленные реплики и
ошибки. Вопросы сопоставляются максимальным 1:1 matching по символьным триграммам
и фиксированным concept-группам. Подробные алгоритмы и ограничения: ../README.md.

До ручного подтверждения verification.status=pending блокирует WER/CER,
Speaker Attribution Accuracy, detection и retrieval quality. После HTML-экспорта
schema и runtime validation должны пройти для подтверждённого JSON. Нормативный
эталон при экспорте не меняется. Прежние сведения о необходимости ручных временных
границ и raw diarization относятся к старой методике, приведённой ниже как история.
Для новой метрики исходные raw-интервалы диаризации не нужны.

### REF_ISSUE_001 — Эвакуационные выходы
Допустим ли один эвакуационный выход с этажа многоквартирного жилого дома при площади квартир около 520 м² и высоте верхнего этажа около 25 м; какие дополнительные условия необходимы?
- SP_1_13130_2020.pdf, PDF стр. 18, `SP_1_13130_2020.pdf:p18:c80`, п. 6.1.1: Непосредственно регулирует число выходов, диапазон 500–550 м², высоту до 28 м, адресную сигнализацию и аварийные выходы квартир выше 15 м.
Проверяемые факты:
- Один выход для площади 500–550 м² допускается при выполнении условий пункта 6.1.1; при высоте до 28 м предусмотрена обычная лестничная клетка и адресные извещатели в прихожих квартир.
- При одном выходе квартиры выше 15 м должны иметь аварийные выходы по 4.2.4.
